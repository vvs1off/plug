the important design rule
each plugin is an isolated DLL, so nothing shares native code. that means shared stuff gets orchestrated through the server, not copy-pasted:

mimik is the only plugin that dumps creds. worm doesn't re-dump — it tells the C2 "infect B," then the C2 auto-fires mimik.collect + kematian.collect on B. same pattern as whisper leaning on kematian.
lanmap is the only plugin that maps the network. router/mitm/worm all read its output instead of rescanning.
this keeps every plugin small and means they compose instead of overlapping.
